Sticker Types

검증된 3가지 충돌 방지 예시 패턴

도트 패턴

Dot Pattern

가장 널리 검증된 방식. 지름 6mm 이상의 원형 점을 가로·세로 5cm 간격으로 배치합니다.

  • 충돌 감소율: 60~70%
  • 채광 영향: 거의 없음
  • 시공 난이도: 쉬움
  • 내구성: 3~5년
  • 비용: ★★☆☆☆

적합 환경: 주거용, 학교, 공공기관 등 모든 유형

수직선 패턴

Vertical Line Pattern

폭 2mm 이상의 수직 선을 10cm 이내 간격으로 배치. 수직 방향 비행 경로를 차단합니다.

  • 예상 충돌 감소율: 55~65%
  • 채광 영향: 미미
  • 시공 난이도: 보통
  • 내구성: 3~5년
  • 비용: ★★☆☆☆

적합 환경: 수직 유리 커튼월, 고층 건물

물결 패턴

Wave Pattern

부드러운 물결 모양으로, 외부 디자인이 벽돌이나 울퉁불퉁한 콘크리트일 경우에 추천

  • 예상 충돌 감소율: 70~80%
  • 채광 영향: 미미
  • 시공 난이도: 보통
  • 내구성: 3~5년
  • 비용: ★★★☆☆

적합 환경: 상업 건물, 디자인 중시 공간
